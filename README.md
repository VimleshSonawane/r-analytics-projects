# Data analytics projects in R

Thirteen data analysis projects in R, from regression studies and hypothesis tests to exploratory analysis of real public datasets. Each project has its own page explaining what it's about, the dataset, the approach, the results with charts, and the takeaways, along with the R code and the full report.

**Author:** Vimlesh Sonawane · [Portfolio](https://vimleshsonawane.com) · [LinkedIn](https://www.linkedin.com/in/vimlesh25)

## Projects

| # | Project | Type | Key finding |
|---|---|---|---|
| 01 | [Social media addiction, mental health, and sleep](01-social-media-addiction-study/) | Regression and hypothesis testing | In a survey of 705 students, addiction explained 89% of the variation in mental health scores and 58% in sleep |
| 02 | [NYC restaurant inspections: dummy-variable regression](02-nyc-restaurant-inspections/) | Regression | Across about 269,000 inspections, violation severity, not borough, drove scores |
| 03 | [NYC motor vehicle collisions: correlation and regression](03-nyc-crash-injuries/) | Regression | Across 65,602 crashes, vehicle count and crash hour were the strongest predictors of injuries |
| 04 | [Maryland labor market: hypothesis tests](04-maryland-labor-market/) | Hypothesis testing | Over 152 months, employment ran below the assumed 65% and high unemployment was far more common than assumed |
| 05 | [Cat weight and meditation sleep: t-test study](05-cat-weight-and-meditation-sleep/) | Hypothesis testing | Male cats were significantly heavier, and meditation modestly improved sleep (+0.62 points) |
| 06 | [Washington, D.C. crime incidents, 2024](06-dc-crime-patterns/) | Exploratory analysis | Across 29,288 incidents, thefts peak in work hours while assaults and robberies peak in the evening |
| 07 | [Airline delays in the United States: exploratory analysis](07-us-airline-delays/) | Exploratory analysis | Air traffic system delays and late-arriving aircraft caused the most delay minutes |
| 08 | [Biometric indicators of diabetes risk](08-diabetes-risk-factors/) | Exploratory analysis | 85% of diabetic patients were obese, and average glucose rose sharply with age |
| 09 | [Book publishing trends, 1990–2020](09-book-publishing-trends/) | Exploratory analysis | Random House published 39% of the output among the six largest publishers |
| 10 | [World Happiness and MLB batting: exploratory analysis](10-world-happiness-and-mlb-batting/) | Exploratory analysis | Freer countries were happier, and a .300 batting average was rare in 1986 |
| 11 | [Probability distributions in practice: staffing, quality control, and sports](11-probability-distributions/) | Probability | Losing one employee sharply cut a call center's chance of hitting its daily target |
| 12 | [Probability fundamentals](12-probability-fundamentals/) | Probability | Joint, conditional, and union probability worked through in code |
| 13 | [Data science salaries: R fundamentals](13-data-science-salaries/) | R fundamentals | Median data science salary of about $101,600, with a long tail of high earners |

## Skills and tools

- **Statistics:** regression (simple, multiple, dummy-variable), correlation, hypothesis testing (one-sample, Welch, and paired t-tests, proportion tests), probability distributions, simulation, Central Limit Theorem
- **Data work:** cleaning, reshaping, date handling, feature engineering, exploratory analysis, geographic plotting
- **R packages:** tidyverse (dplyr, ggplot2, tidyr, readr, lubridate, stringr), janitor, psych, stargazer, plotly, MASS, palmerpenguins

## Running the code

Datasets aren't included in this repository because of their size. Each project page names the dataset and where to get it. Download the file, place it in that project's folder, and run the script in R or RStudio.
